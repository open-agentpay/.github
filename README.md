## Why AgentPay?

AI agents are starting to pay for APIs and services on their own. Without guardrails, a buggy or runaway agent can drain a budget in minutes.

AgentPay sits between agents and the services they pay for, and enforces policy **before** any money moves.

## Core capabilities

- 🛡️ **Policy engine**: budgets, rate limits, and allow/deny rules per agent and tenant
- 💸 **Payment gateway**: a self-hosted gateway where API providers register an API with a price and get paid per request (x402)
- 🧾 **Audit and traceability**: a complete record of what each agent paid for, and why
- 🏢 **Multi-tenant**: RBAC, API keys, and a management console
